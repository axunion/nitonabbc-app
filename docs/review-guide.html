1全体像・画面構成

このアプリは LINE 認証のみで利用できる教会メンバー向け PWA です。下部のタブバーで「教会」「設定」の 2 タブを切り替え、タブごとに独立した画面階層を持ちます。

2権限モデル

アクセス可能画面
サーバー側チェック メンバー管理API（/api/admin/*）とテンプレート保存（PUT /api/bulletin-template）はサーバー側でも管理者チェックが行われます。フロントエンドの制御とは独立して機能します。

3各画面の確認

ログイン画面

/login（認証前のみ表示） 全員

未認証ユーザーが最初に見る画面。LINE ログインボタンのみが表示されます。

ログインフロー
確認項目
  • LINE ログインボタンが中央に表示されている
  • ボタンをタップすると LINE の認証画面に遷移する
  • LINE 認証後、ダッシュボード（/）にリダイレクトされる
  • すでにログイン済みの場合、このページは表示されない（ダッシュボードへ自動遷移）
  • 招待されていない LINE アカウントでログインした場合のエラーハンドリングを確認
ローカル開発 DEV_AUTH=true の場合、LINE 認証をスキップして「Dev Admin」として自動ログインします。

ダッシュボード

/ 全員

ログイン後の最初の画面。3 つの機能ウィジェットへのエントリポイントです。

ダッシュボードのレイアウト構成
確認項目
  • 「週報」ウィジェットをタップすると /bulletin（週報一覧）へ遷移する
  • 「経費」ウィジェットをタップすると iframe オーバーレイが開く
  • 「ファイル」ウィジェットをタップすると iframe オーバーレイが開く
  • iframe は画面を下にスワイプ、または Escape キーで閉じられる
  • タブバーが画面下部に常時表示されている
  • 「教会」タブがアクティブ（ゴールド色）になっている
  • 「設定」タブをタップすると設定画面へ遷移する
  • セーフエリア（iPhone ノッチ・ホームインジケーター）を侵食していない
  • ウィジェットのグリッドレイアウトが崩れていない

週報一覧

/bulletin 全員

礼拝プログラム（週報）の一覧。年月セレクターで表示月を切り替え、各日曜日のカードを表示します。

確認項目
  • ヘッダー左に戻るボタン（← 丸形ガラスボタン）が表示され、タップするとダッシュボードに戻る
  • 年・月のセレクターが表示され、切り替えると対象月の週報一覧が更新される
  • その月の日曜日ごとにカードが表示される
  • 作成済みの週報カードにプログレスバーが表示される（filled / total）
  • 作成済みカードをタップすると週報詳細（/bulletin/:id）へ遷移する
  • 未作成の日曜日カードをタップすると週報作成フォーム（/bulletin/new?date=...）へ遷移する
  • 次回日曜日は未作成でもカードが表示される
  • スクロール時にヘッダーのフロスト背景が出現する

週報詳細

/bulletin/:id 全員

特定の週報の全セクションを閲覧します。自分が未記入の項目があると「記入する」CTA が表示されます。

確認項目
  • 礼拝日（サービス日付）が大見出しで表示される
  • ページ上部に全体の進捗プログレスバーが表示される（例: 7/12）
  • 未記入の担当項目がある場合「記入する」ボタンが表示され、タップすると編集フォームへ遷移する
  • ヘッダー右に「編集」ボタンがあり、タップすると /bulletin/:id/edit へ遷移する
  • 各セクションが正しい種別に応じたレイアウトで表示される（以下のセクション種別一覧を参照）
  • worship-program: 礼拝プログラム項目が一覧表示される
  • assignments: 役割と担当者名が表示される
  • weekly-verse / monthly-song: 聖句・賛美歌情報が表示される
  • attendance: 各集会の出席数が表示される
  • 戻るボタンで週報一覧に戻る

週報作成・編集フォーム

/bulletin/new  ／  /bulletin/:id/edit 全員

週報を新規作成または既存の週報を編集します。テンプレートに定義されたセクションがすべて表示されます。

確認項目（新規作成）
  • 一覧から「未作成日曜日」をタップした場合、日付フィールドがプリフィルされている
  • テンプレートで定義した全セクションがフォームに表示される
  • 各セクション種別ごとの入力UIが正しく機能する（後述のセクション種別を参照）
  • worship-program: 各項目のフィールドに値を入力できる
  • assignments: ドロップダウンからメンバーを選択できる
  • announcements: 「追加」ボタンで項目を増やせる
  • 保存ボタンをタップすると週報詳細ページへ遷移する
確認項目（編集）
  • 既存データが各フィールドに正しく読み込まれている
  • 変更を保存すると詳細ページに反映される
  • 別のメンバーが入力済みの項目も閲覧・編集できる（権限制限なし）

設定画面

/settings 全員

ユーザー情報の確認、言語切替、PWA インストール案内、管理者向けメニューを集約します。

確認項目（全員）
  • ユーザー名（表示名）が正しく表示されている
  • 言語セレクト（日本語 / English）が表示され、切り替えるとUI全体の表示言語が変わる
  • PWA 未インストール時のみ「ホーム画面に追加」案内セクションが表示される
  • Android/Chrome: ボタンをタップするとインストールプロンプトが表示される
  • iOS Safari: 手順テキスト（共有ボタン → ホーム画面に追加）が表示される
  • PWA インストール済みの場合、インストール案内セクションが非表示になる
確認項目（管理者のみ）
  • 「メンバー管理」リンクが表示され、タップすると /settings/members へ遷移する
  • 「週報テンプレート設定」リンクが表示され、タップすると /settings/bulletin-template へ遷移する
  • メンバーロールでログインした場合、これらのリンクは表示されない

メンバー管理

/settings/members 👑 管理者のみ

メンバーの追加・編集・招待リンク発行・LINE 連携状態の管理を行います。

確認項目
  • メンバー一覧がカード形式で表示される
  • 各カードに名前・ロール（Admin/Member）・LINE連携状態・アクティブ状態が表示される
  • 「メンバーを追加」ボタンをタップするとフォームダイアログが開く
  • 名前・ロールを入力して保存するとメンバーが追加される
  • 追加後、一覧に新しいカードが表示される
  • 各メンバーカードの「編集」ボタンで名前・ロール変更ダイアログが開く
  • 「招待リンクをコピー」ボタンをタップするとクリップボードに招待URLがコピーされる
  • LINE 連携済みメンバーに「再招待」ボタンが表示され、タップすると連携リセット＋新トークン発行される
  • 「無効化」ボタンで該当メンバーが非アクティブになる（自分自身は無効化できない）
  • メンバーロールのユーザーがこのページを開こうとするとダッシュボードにリダイレクトされる
注意 無効化は取り消せます（管理者が再度有効化できます）が、操作前に確認ダイアログが出るか確認してください。

週報テンプレート設定

/settings/bulletin-template 👑 管理者のみ

週報に含まれるセクションの構成・順序・表示設定をカスタマイズします。変更後に作成された週報に反映されます。

確認項目（セクション操作）
  • 既存セクションが縦に並んで表示される
  • 各セクション行を展開/折り畳みできる（タップで詳細設定エリアが表示される）
  • 表示/非表示トグルで週報フォームへの表示を切り替えられる
  • ↑↓ ボタンでセクションの順序を入れ替えられる
  • セクションラベル（見出し名）を編集できる
  • 削除ボタンでセクションを削除できる（確認不要か確認）
  • 「セクションを追加」ボタンをタップすると種別選択メニューが表示される
  • 新しいセクションを追加すると一覧の末尾に追加される
確認項目（種別別の設定）
  • worship-program: テンプレートアイテム（説教・賛美歌など）の追加/編集/削除、フィールド設定
  • announcements: サブヘッディング（見出し候補）の編集
  • assignments: 役割名リストの編集（例: 礼拝司会、奏楽）
  • attendance: 集会・会議種別の追加/削除
  • service-meta: カスタムフィールドの追加/削除（key・label・inputType）
  • financial-summary: 収支項目の追加/削除（key・label・unit）
確認項目（保存と反映）
  • 「保存」ボタンをタップするとサーバーにテンプレートが保存される
  • 保存後、新規作成フォームを開くと変更が反映されている
  • 既存の週報詳細は変更されない（テンプレートは新規作成時のみ参照）

4機能フロー

招待フロー（メンバー登録の流れ）

招待リンクによる LINE 連携フロー
招待フローの確認項目
  • 管理者がメンバーを追加し、招待リンクをコピーできる
  • 招待リンク（/api/invite/:token）をブラウザで開くと LINE 認証にリダイレクトされる
  • LINE 認証後、ユーザーレコードに LINE アカウントが紐付けられログイン完了する
  • 同じ招待リンクを 2 回使えないことを確認（inviteUsed フラグ）
  • 「再招待」操作で LINE 連携がリセットされ、新しい招待トークンが発行される
