# 仁戸名聖書バプテスト教会 メンバーアプリ 仕様書

## 概要

仁戸名聖書バプテスト教会のメンバー（約30名）が利用するWebアプリケーション。

- **形態**: PWA（Progressive Web App）
- **UI方針**: ライトテーマ + フロスト白グラスモーフィズム（"God's Glory" テーマ）。Deep Gold アクセント
- **認証**: LINE認証のみ
- **運用**: 小規模のため、イレギュラーな対応は管理者が手動でサポート
- **多言語対応**: 日本語・英語。将来的な言語追加も考慮するが当面は2言語
- **開発方針**: 機能を段階的に追加していく

## 権限モデル

シンプルな2ロール構成。

| ロール | 説明 |
|--------|------|
| 管理者 | 全権限（ユーザー管理 + テンプレート設定） |
| メンバー | 閲覧・入力・編集・PDF出力 |

## 技術スタック

- Solid.js + TypeScript（SPA）
- Vite（ビルド）+ pnpm（パッケージマネージャー）
- @kobalte/core + CSS Modules（UI）
- Hono（APIサーバー）
- Cloudflare Workers + static assets（デプロイ）
- Cloudflare D1（ユーザーDB）
- Cloudflare KV（セッションストア）
- LINE認証（LINE Login API）

## ナビゲーション

### ボトムタブバー

画面下部に固定表示される iOS 風タブバー。2 タブ構成:

| タブ | ラベル | アイコン | 遷移先 |
|------|--------|---------|--------|
| 教会 | 教会 / Church | Church | `/`（ダッシュボード）。週報・管理画面等もこのタブ配下 |
| アカウント | アカウント / Account | CircleUser | `/more`（アカウント設定ページ） |

アクティブタブは Deep Gold アクセント色で表示。`env(safe-area-inset-bottom)` 対応。

### ヘッダー

画面上部に固定表示されるシンプルなタイトルバー。

- 中央: 教会名（デフォルト）または各ページのタイトル
- 右: コンテキスト依存のアクションボタン（オプション）

### アカウントページ (`/more`)

ユーザー情報と設定機能を集約:

- ユーザー名・ロール表示
- 管理画面へのリンク（管理者のみ）
- 言語切替（セレクトボックス: 日本語 / English）
- ログアウト

## トップページ（ダッシュボード）

モバイルファーストのダッシュボード画面。各機能へのエントリポイント。

### レイアウト

- **メインエリア**: ウィジェット風カード配置（大小カード混合の 2 カラムグリッド）
  - 機能選択時: アプリ内画面、または iframe で外部サービスを全画面表示

### アイコン一覧

| アイコン | 種別 | 動作 |
|---------|------|------|
| 週報 | アプリ内 | アプリ内で週報画面へ遷移 |
| 経費精算 | iframe | サブドメインの既存サービスを iframe で表示 |

> 機能追加に応じてアイコンを増やしていく。同じドメインのサブドメインで運用中の外部サービスは iframe で埋め込み、ヘッダーは維持したままシームレスに利用できるようにする。iframe 埋め込み先には `X-Frame-Options` の許可設定が必要。

## 管理画面

管理者のみアクセス可能なページ。アカウントページ内のリンクからアクセス。

### メンバー管理

- メンバーの追加・編集・削除
- 招待リンク一覧の表示・一括コピー（LINEグループ等に貼り付けて共有）
- 各メンバーのLINE紐付け状況の確認
- 紐付け解除・招待リンク再発行
- ロール変更（管理者/メンバー）

### 週報テンプレート設定

- 礼拝プログラムの項目・順序の編集
